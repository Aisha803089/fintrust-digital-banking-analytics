# FinTrust Digital Bank: Financial Intelligence & Digital Banking Analytics

## Project Overview

FinTrust Digital Bank is a data analytics portfolio project focused on exploring customer information and transaction activities to generate business insights and support data-driven decision-making.

The project demonstrates how Excel, MySQL and Power BI can be used together to clean, analyse and visualise banking data.

**Note:** This project uses synthetic data for educational and portfolio purposes. It does not contain actual customer or banking records.

## Tools & Technologies

- **Microsoft Excel:** Data cleaning, duplicate checks and data quality assessment.
- **MySQL:** Data querying, aggregation and business analysis.
- **Power BI:** Interactive dashboards, KPI reporting and visualisation.

## Dataset Overview

The project contains two datasets:

| Dataset | Records | Columns |
|---|---:|---:|
| Customer Data | 1,500 | 12 |
| Transaction Data | 12,000 | 11 |

The `Customer_ID` field connects customer information with transaction records.

## Key Performance Indicators

The Power BI dashboard presents the following KPIs:

- **Total Customers:** 1,500
- **Total Transactions:** 12,000
- **Transaction Success Rate:** 90.47%
- **Risk Review Rate:** 19.60%

## Key Business Insights

1. The Everyday customer segment has the highest customer count, with 711 customers.
2. Mobile App is the most frequently used transaction channel, recording 5,102 transactions.
3. Transfers represent the highest transaction volume among transaction types.
4. The risk review rate is 19.60%, highlighting transactions flagged for further review.

## Business Recommendations

- Improve the reliability and user experience of mobile banking services.
- Investigate unsuccessful transactions to identify possible causes and improve transaction success rates.
- Review flagged transactions through appropriate monitoring procedures.
- Use customer segmentation to develop more targeted banking services.
- Continue monitoring transaction patterns to support operational decision-making.

## Data Limitations

- The datasets are synthetic and do not represent real banking activities.
- The `Risk_Review_Flag` is an educational indicator and should not be interpreted as confirmed fraud.
- The `Amount_NGN` field contains dollar symbols in the imported data. Since the currency denomination could not be independently verified, transaction values should not be interpreted as confirmed Nigerian Naira amounts.
- Findings are limited to the information available in the supplied datasets.
